KEK 1992 WWW — 表示環境確認用

1992年9月30日前後のKEK最初期WWWについて、公開資料から確認できるHTMLと、当時の表示環境を分けて確認するための仮復元です。確定した「当時の実画面」ではありません。

操作方法

復元画面は「数字 ＋ RETURN」で操作します

CERN VIEW と KEK 2002 RECONSTRUCTION VIEW では、画面内のリンク番号（1〜7）をキーボードで入力し、RETURN を押してください。マウスで画面内のリンクをクリックする方式にはしていません。

これは、初期Line Mode Browserの「参照番号を入力してリンクをたどる」操作を確認できるようにしたものです。現在復元できていないリンク先は、その旨を表示します。

仮説表示

CERN VIEW

森田様がCERN側からKEKのHTMLを確認した際の表示候補。Line Mode Browser系の文字端末表示を想定しています。

公開資料に基づく再現

KEK 2002 RECONSTRUCTION VIEW

KEKの2002年記事・森田様の講演資料に掲載された緑色の「KEK INFORMATION」画面に寄せた比較表示です。

根拠資料

SOURCE MATERIALS / 資料

KEK・CERN・W3Cなどの公開資料を、何の根拠として使っているか分かるように整理しています。PDFや当時資料を元サイトから確認できます。

現在の整理

項目現時点
1992年9月30日の公開場所ftp://kekux.kek.jp/kek/html/kek.html と記録されている
ページ本文復元HTMLが現存し、本文・リンク構造を確認可能
リンク操作Line Mode Browserは番号入力によるリンク選択を採用。RETURNを伴う操作資料も存在
CERN側の実端末機種・表示色・行列数・全画面/ウインドウ等は本人確認が必要

根拠資料

この復元で参照している公開資料は、SOURCE MATERIALS / 資料 にまとめています。資料ごとに「何が確認できるか」も記載しています。

このディレクトリは noindex / nofollow / noarchive を指定し、公開トップページからリンクしない確認用ページを想定しています。ただしURLを知る人は閲覧できます。
