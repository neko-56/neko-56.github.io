復元画面について

表示候補は調査途中の仮説です。見た目を「古く見せる」ための走査線、ぼかし、発光、画面湾曲などの演出は使用せず、確認できるレイアウト・文字・操作を優先します。番号を入力して Return でリンクを選択する操作は、資料で確認できる範囲で実際に試せるようにしています。CERN側・KEK側の中心画面はCSSで描いた静止模型ではなく、同じLine Mode Browserエミュレーションエンジンを異なる環境プロファイルで動かします。

このサイトは調査途中の確認用ページです。検索エンジン向けに noindex / nofollow / noarchive を指定していますが、URLを知る方の閲覧を防ぐアクセス制御ではありません。
