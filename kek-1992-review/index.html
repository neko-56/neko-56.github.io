KEK 1992 WWW — 表示環境確認用

1992年9月30日前後のKEK最初期WWWについて、公開資料から確認できるHTMLと、当時の表示環境を分けて確認するための仮復元です。確定した「当時の実画面」ではありません。

操作方法

復元画面は「数字 ＋ RETURN」で操作します

CERN VIEW と KEK 2002 RECONSTRUCTION VIEW では、画面内のリンク番号（1〜7）をキーボードで入力し、RETURN を押してください。マウスで画面内のリンクをクリックする方式にはしていません。

これは、初期Line Mode Browserの「参照番号を入力してリンクをたどる」操作を確認できるようにしたものです。現在復元できていないリンク先は、その旨を表示します。

実機エミュレーション / Phase 1

KEK Web Display Emulator

歴史HTMLを現代ブラウザで直接レイアウトせず、Line Mode Browser相当の固定幅整形、参照番号、ページ送り、プロンプト、キーボード操作を80×24文字画面へ出力し、Canvas framebufferへ描画します。CERN/KEKの端末プロファイルはブラウザコアから分離しています。

仮説表示

CERN VIEW

史料からの第一候補として、CERN共用端末室のIBM 3270系固定表示環境＋Line Mode Browserを再構成。24×80、単色CRT、7×9系文字セルを基準にし、型番未確定を明示しています。

公開資料に基づく再現

KEK 2002 RECONSTRUCTION VIEW

KEKの2002年記事・森田様の講演資料に掲載された緑色の「KEK INFORMATION」画面に寄せた比較表示です。
