DISPLAY MODEL · INTERACTIVE EMULATOR

KEK Web Display Emulator

現存する復元ページ等に基づくHTMLをLine Mode Browser挙動モデルへ通し、入力・ページ送り・prompt・参照番号・bitmap glyphを動的に描画する研究用エミュレータです。歴史画面をCSSで組まず、Canvas framebufferへ描画します。

研究用エミュレータ UI v0.54
操作: 画面内の参照番号を入力して RETURN。キーボード入力はCanvasへ送られます。
表示設定・研究用設定

通常閲覧では変更不要です。表示profileや検証条件を比較するときだけ開いてください。

Address: Input buffer: Unresolved request: none
表示方針: エミュレート画面には、元HTML本文または当時のLine Mode Browserが生成すると確認できる内容だけを表示します。 研究用説明は画面外に置き、表示面に合わせて画面を小さくすることもしません。
Historical glyph source: 機種ごとの標準仕様または実機由来の公開font sourceが確認できたprofileでは、そのfontを自動読込してエミュレートします。KEK DECtermは検証済みDEC Terminal 8×15 bitmap、IBM RS/6000参照はMeyrin、X11比較は標準fixed bitmap、IBM 3270はx3270 9×14 bitmapをZIP内から読み込みます。NeXTSTEP native TerminalはOhlfs原本を配布せず、再構成資産の来歴を独立管理します。
研究用フォントoverride 実ULTRIX抽出BDFなどとの比較専用です。公開ページの通常表示には使用しません。

SPECIFICATION-DRIVEN / PHASE 6.5 · UI v0.54

Current profile

Evidence / uncertainty

    Font state:
    fontは「似た等幅フォント」ではなく、機種・OS・端末の標準仕様または実機再構成の根拠がある公開sourceをprofileごとに選びます。KEK DECtermではULTRIX 4.3 targetとのraster照合結果も保持しています。

    Historical font verification / runtime selection

    historical targetと実際に描画へ使う公開font sourceを分けて記録します。DECはglyph raster一致・SHA-256・ライセンス来歴を検証し、IBM RS/6000・X11等も出自とライセンスをprofile情報に保持します。

    画面サイズの扱い

    研究用エミュレータを単独で開いた場合、「自動」は100%未満へ縮小せず、pixel-for-pixel確認を優先します。一方、森田様向けの埋め込み表示では横スクロールを避けるため、ネイティブframebufferを保持したまま表示サイズだけを幅に合わせます。

    CRTをぼかす処理は入れていません。写真撮影時のボケや走査同期の再現が必要になった場合は、別の「撮影モード」として扱います。

    Phase 6.5 — September prompt evidence discipline

    保守モードでは、1992年2月18日の同時代図で直接確認できるprompt tokenだけを表示します。具体的には参照番号、必要時の Return for more、末尾の Help or Quit: です。

    Back、Up、Find <keywords> は後の資料で系譜を確認できますが、1992-09-30のexact executableでの表示条件・語順をまだ直接確認できないため、September conservative画面には出しません。コマンド機能とprompt上の表示証拠を分離しています。

    Phase 6.4 — 1992 Line Mode Browser behavior bounds

    1992年2月18日作成の同時代論文図にある端末例から、period promptの Return for more, Help or Quit: という語順・大文字小文字を保守モードへ反映しています。SOURCEは単独で現在文書のsourceを表示するコマンドではなく、command-line -sourceとinteractive SOURCE prefixを分離しています。

    Phase 6.3 — graphics / X-server font branch

    KEK runtimeを75dpi/100dpiの単一候補へ固定せず、X server / graphics optionの条件分岐として保持します。表示glyph自体は、公開term14.bdfとULTRIX 4.3媒体のterminal10.pcfが8×15正規化で195/195一致するため変更していません。

    Phase 6.1 — DECterm window structure / screen-mode evidence

    historical targetはULTRIX 4.3 RISC媒体から検証したDEC Terminal V2.2系bitmapです。公開許諾されたX Consortium系term14.bdfを自動読込し、glyph planeを80×24＝640×360pxへ1:1 mappingします。ライセンス上の「配布しない」制約は設けません。
