# CERN-level reconstruction method

The target is a functional, evidence-bounded reconstruction rather than a retro-styled mockup.

Reference methodology: CERN 2019 WorldWideWeb Rebuild production notes. Their process combined an experiential goal, surviving code, period hardware, and oral history.

For this KEK project:

1. Historical HTML is input data.
2. Line Mode Browser behavior is modeled separately from display hardware.
3. Environment profiles (CERN / KEK) select only evidence-supported geometry/font/display facts.
4. The historical display is drawn to a Canvas framebuffer; CSS does not construct the terminal text screen.
5. Unresolved remote links are never replaced with invented historical pages.
6. Confirmed, inferred, and unknown claims remain separate.
7. Morita testimony is retained as its own provenance layer.
8. Optical CRT effects are excluded from the default viewed-display reconstruction.
