DEC graphics / X-server font branch / Phase 6.3

KEK側 DEC Terminal runtime branch

Phase 6.3では、v0.22の「KEK runtime第一候補=75dpi/14pt」という順位付けを取り消しています。DECの1991年価格表には、DECstation 5000/125 + VRT19としてPM322-KN（PX 8-plane 2D）とPM323-KN（PXG 8-plane 3D）の両方があります。展示機のgraphics optionはまだ同定できていません。

ULTRIX/UWS 4.3資料では、Xwsは75dpi、Xwst3dは100dpiを既定使用します。DECterm Little Fontは75dpiで14pt、100dpiで10ptです。したがって、実機のgraphics optionまたは/etc/ttysのX server commandを確認するまで75/100dpiを一意に決めません。

glyph自体は安定しています。公開75dpi term14.bdfと、ULTRIX 4.3媒体から実抽出した100dpi terminal10.pcfは8×15正規化で195/195 glyphs、ASCII 95/95一致です。

W3 / 1992 period behavior / Phase 6.4

Line Mode Browser — 1992 behavior bounds

1992年のW3論文に掲載されたterminal clientの模式図には、1-9, Return for more, Help or Quit:、 ERROR CODES、 o ...、anchor直後の[1]が直接示されています。これはKEK実画面の写真ではありませんが、1992年前半のLine Mode Browser表示規則を同時代資料から拘束できる重要な根拠です。

1992-11-03保存資料では、reference number + RETURN、page length 24、width既定78/79/80（system dependent）、command-line -source（v1.2a+）を確認できます。別のSourceExamplesはinteractive SOURCEをv1.3+のprefixとして説明し、SOURCE単独では現在文書sourceを表示しないと明記します。

したがって1992-09-30のexact binary revisionは未確定のまま、2月同時代図をSeptember conservative mode、11月3日保存文書をreference boundaryとして分離しています。W3Cの2016 FTP保存inventoryでもversioned Line Mode sourceは2.11以降しか列挙されず、1.x sourceは現在の保存inventoryから直接取得できません。

手元検証 / ULTRIX 4.3

DEC Terminal 100dpi 10pt フォント候補の実在確認

この調査で使用したULTRIX 4.3 RISC媒体の UDWFONT15430 サブセットから、terminal10.pcf を抽出してメタデータを確認しました。XLFDは -DEC-Terminal-Medium-R-Normal--14-100-100-100-C-80-ISO8859-1、文字セルは8×15で、100dpi / 10ptのDEC Terminal候補と一致します。

ただし、これはフォント候補が媒体内に存在することの確認です。 1992年9月のKEK実機が100dpi側を実際に選択していたことの証明ではありません。75dpi / 100dpiのどちらだったかは、graphics optionやX server起動条件などの確認が必要です。

フォントファイル自体はこの確認サイトでは再配布せず、メタデータと検証結果だけを記録します。
