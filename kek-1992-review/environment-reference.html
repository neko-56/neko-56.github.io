当時の表示環境に関する参考資料

1992年前後のWWWが、どのような端末・ブラウザ・画面で使われていたのかを考えるための資料です。

位置づけ: ここに掲載する機器や復元画面が、森田様が1992年9月に実際に使用したものだと断定するものではありません。比較・確認のための参考資料です。
CERN

CERNによる初期WWW環境の復元

CERNは、最初のWebサイトだけでなく、初期のブラウザを「当時どのように見え、どのように操作したか」という体験まで含めて復元する取り組みを行っています。今回のKEK表示環境の復元では、この「画面を似せるだけでなく、当時の利用体験を再構築する」という方法を基本方針にします。

最初のWebサイトの復元

CERNは2013年、世界最初のWebサイト info.cern.ch の復元プロジェクトを開始しました。

CERN: The birth of the Web ↗

Line Mode Browserの復元

端末上でテキストとしてWebを閲覧するLine Mode Browserについて、CERNは2013年にシミュレーターを再現しました。GitHubにはCERN simulationのmirrorが残っています。

CERN: Why bring back the line-mode browser? ↗
CERN Line Mode Browser simulation mirror ↗

WorldWideWebブラウザの再現

2019年には、NeXT上で動いた最初のWorldWideWebブラウザ／エディタを、現代のブラウザ上で再現するプロジェクトも行われています。

CERN 2019 WorldWideWeb Rebuild ↗

IBM 3270系という候補

CERN職員の後年の回顧には、初期Line Mode Browserを固定サイズのIBM 3270 displayで使ったという記述があります。ただし、森田様が使用した端末を直接特定する資料ではありません。

実際に使った端末は未確定

端末の型番、文字色、接続方式、ブラウザの種類、CERNでHTML作成後に実際にブラウザ表示したかは、現時点の公開資料だけでは確定していません。

KEK側の比較材料

DECstation / ULTRIX / DECwindows

KEK側については、DECstation 5000/125、ULTRIX、DECwindows / DECterm、Line Mode Browser、当時の端末フォントなどを調べています。

DECstation 5000/125

KEK側実機候補の本体・グラフィックス・モニタ構成について、DECの同時代価格表や保守資料を照合しています。

ULTRIX / DECwindows / DECterm

80桁×24行、固定幅Terminal font、画面解像度、X serverの75dpi / 100dpi分岐などを技術資料から検証しています。

フォントの実物確認

ULTRIX 4.3媒体から100dpi / 10ptのDEC Terminal候補フォントが実在することを確認しています。ただし、それが1992年のKEK実機で選択されていたことまでは確定していません。

最も重要な未確認点: KEKのWWWサーバー自身でWWWブラウザを起動し、自分自身が配信しているページを表示確認していたかどうかは、まだ確認できていません。現在のKEK側画面は「もしそのような使い方をしていた場合」の比較候補です。
