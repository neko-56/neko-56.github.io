当時の表示環境に関する参考資料

1992年前後のWWWが、どのような端末・ブラウザ・画面で使われていたのかを考えるための資料です。

位置づけ: ここに掲載する機器や復元画面が、森田様が1992年9月に実際に使用したものだと断定するものではありません。比較のための参考資料です。
CERN

CERNによる初期WWW環境の復元

CERNは、最初のWebサイトだけでなく、初期のブラウザを「当時どのように見え、どのように操作したか」という体験まで含めて復元しています。今回、森田様に表示候補を見ていただく際にも、この考え方を参考にしています。

最初のWebサイトの復元

CERNは2013年、世界最初のWebサイト info.cern.ch の復元プロジェクトを開始しました。

CERN: The birth of the Web ↗

Line Mode Browserの復元

端末上でテキストとしてWebを閲覧するLine Mode Browserについて、CERNは2013年にシミュレーターを再現しました。GitHubにはCERN simulationのmirrorが残っています。

CERN: Why bring back the line-mode browser? ↗
CERN Line Mode Browser simulation mirror ↗

WorldWideWebブラウザの再現

2019年には、NeXT上で動いた最初のWorldWideWebブラウザ／エディタを、現代のブラウザ上で再現するプロジェクトも行われています。

CERN 2019 WorldWideWeb Rebuild — Production Details ↗

今回の確認で参考にしている点

HTML本文を残すだけでなく、「どの端末・ブラウザで」「どのように描画され」「どのように操作されたか」を分けて調べる、という考え方です。

1992年前後の端末・Line Mode Browser

1991年にLMBが動いた機種

W3Cに残るTim Berners-Leeの初期WWW史には、1991年3月にLine Mode Browserが限定公開された環境として "priam" VAX、RS/6000、Sun-4 が明記されています。

W3C: A Little History of the World Wide Web ↗

IBM RS/6000は実機復元資料がある

CERNの2013年Line Mode Browser復元では、古いIBM RISC System/6000 AIX機で初期ブラウザを動かし、表示やキーボードを実機から参照しています。森田様の使用機種と確定したわけではありませんが、表示検証の参考になる候補です。

NeXT上のLine Mode Browserも候補から除外しない

CERNにはNeXT環境があり、Line Mode Browser自体は移植可能な文字端末向けブラウザでした。森田様がNeXT上でLMBを使った直接証拠は未確認ですが、NeXTSTEP Terminal.app上の候補と、color NeXT + X11/xtermで講演資料配色を再現する候補を比較対象にしています。WorldWideWeb GUIブラウザは別系統の参考資料としてCERN公式復元を参照します。

CERN 2019 WorldWideWeb Rebuild — Production Details ↗

最初のWWWサーバーにはHTMLの説明が公開されていた

Tim Berners-Leeは、HTML・HTTP・URIの仕様を最初のWWWサーバー上で公開して普及を促したと回想しています。1992年11月3日の保存スナップショットには、HTMLのTags、Finding Examplesなど、HTMLを書く人が参照できる資料が残っています。

森田様が1992年9月にこれらを実際に参照したかは未確認です。Berners-Lee氏から直接教わったのか、WWW上の説明・Example・既存ページを参考にしたのかを確認したい事項として残します。

森田様の実際の端末は未確定

上記は「当時CERNで存在・動作が確認できる候補」です。1992年9月30日に森田様が実際に使用した端末、表示色、フォント、ブラウザはまだ特定できていません。

候補を切り替えて比較する

KEK側の比較材料

DECstation / ULTRIX / DECwindows

KEK側については、本体をDECstation 5000/125として固定し、ULTRIX、DECwindows / DECterm、Line Mode Browser、当時の端末フォント、現存モニタを調べています。

DECstation 5000/125

KEK側のコンピューター本体はDECstation 5000/125として扱います。未確定なのは主にgraphics option、X server、ブラウザをどの表示経路で使ったかです。

VRT19系 / Sony OEM 19インチ候補

KEK公式の現存実機写真と同時代DEC資料を照合し、DEC VRT19系を有力候補として扱います。VRT19-DA/HAはSony GDM-1960/1961 OEMとして知られ、DEC資料系統では1280×1024です。正確なサブモデルは現物背面ラベルの確認待ちです。

ULTRIX / DECwindows / DECterm / フォント

80桁×24行、DECtermのlight-on-dark / dark-on-light、X serverの75dpi / 100dpi分岐、ULTRIX 4.3媒体内のDEC Terminal bitmapを検証しています。どのresourceがKEK実機で使われていたかは未確定です。

最も重要な未確認点: KEKのWWWサーバー自身でWWWブラウザを起動し、自分自身が配信しているページを表示確認していたかどうかは、まだ確認できていません。加えて、現存モニタの背面ラベルをKEKで確認できれば、VRT19の正確なサブモデルとSony OEM型番を確定できる可能性があります。

KEK側の現在の表示候補を見る

文字表示

機種・環境ごとのフォント／glyph source

フォントは「昔風に見えるもの」を選ぶのではなく、当時の標準仕様、実機由来の復元、公開されたbitmap sourceの順に根拠を確認して使います。

DECstation / DECterm

DEC/X Consortium系の term14.bdf を使用します。ULTRIX 4.3媒体から確認したDEC Terminal targetと正規化後195/195 glyph、ASCII 95/95で一致しています。8×15 bitmapをCanvasへ1:1で描画します。

公開BDF source ↗ · ライセンス記録

IBM RISC System/6000

CERN HackdayのMeyrinを使用します。IBM System/6000で文字を表示してスクリーンショットを取り、glyphを再構成したフォントです。プロジェクトはOFL-1.1です。

Meyrin project ↗

Sun-4 / NeXT + X11

X11 sample implementationの標準 fixed familyから6×13 bitmapを使用します。X11の標準環境を再現するためのsourceで、現代的な代替等幅フォントではありません。

X.Org font documentation ↗

NeXTSTEP Terminal.app

当時の標準設定としてOhlfs 10ptを基準にします。CERNの2019年復元でも実機NeXT上の文字を撮影し、pixel単位で字形を再構成しています。元のOhlfsを別フォントで「同じもの」とは扱いません。

CERN 2019 Typography ↗

IBM 3270-class

x3270 4.1ga10 自身の14pt 3270.bdf（9×14、431 glyph）を完全な形でサイト内に同梱して使用します。BDFは通常のASCII/Unicode順ではなく 3270cg character-generator順なので、エミュレータ側で STARTCHAR 名を使ってASCII表示文字を正しい3270字形へ対応させます。表示時に外部サイトへfontを取りに行かず、Courier等への置換も行いません。

x3270 4.1ga10 source distribution / x3270/3270.bdf · ライセンス・由来記録

PRIAM VAX

VAXはホスト機種であり、接続された端末の文字発生器までは決まりません。そのため「VAX用フォント」を作らず、端末が特定できた時点で対応するglyph sourceを追加します。

帰属未確認の重要資料

森田様の講演資料にある「薄緑背景・白文字」の画面

この画像は、薄緑背景に白文字、横長のウィンドウ形状で示されています。森田様ご本人が講演で再現画像として使用されているため、配色や形状を単なる装飾として切り捨てず、復元候補を考える重要な資料として扱います。

ただし、CERN側の表示を意図したものか、KEK側の表示を意図したものか、後年の再現作業で作った表示なのかは未確認です。そのため、同じ配色をCERN側のNeXT＋LMB候補と、KEK側のDECstation＋DECterm候補の双方で比較できるようにしています。

また、この横長比率は物理モニタ全面ではなく、GUIデスクトップ上に開いたターミナル・ウィンドウだったと考えると説明できます。この点も森田様への確認対象です。
