操作: 番号（1〜7）を入力し RETURN。ここでは DECwindows 上の DECterm で Line Mode Browser を実行した場合を第一候補として表示しています。

推定仕様

本体DECstation 5000/125
OSULTRIX / ULTRIX Worksystem Software（正確なバージョン未確認）
モニタ候補DEC VRT19系 19インチ Trinitron。Sony GDM-1960 / GDM-1961 OEM系が有力候補。
ラスタ1280 × 1024（5:4）。VRT19-DA/HA系資料と整合。
ブラウザLine Mode Browser。KEKへの導入記録は1992-04-14。
端末候補DECwindows上の DECterm。標準論理サイズ 24 rows × 80 columns。
標準フォント候補DEC Terminal fixed-width 系。DECterm資料では14-point級 / 80-column用が標準。
画面モードlight-on-dark を標準候補として採用。実際の色設定は未確認。

推定根拠

  • KEK側の実機は DECstation 5000/125 と確認されている。
  • 1992-04-14にKEKへ Line Mode Browser をインストールした記録がある。
  • DECwindows/DECtermの同時代資料では、標準端末サイズは24行×80桁、固定幅Terminal font、ブロックカーソルを使用。
  • DECstation 5000世代にはVRT19系19インチCRTがあり、1280×1024表示。VRT19-DA/HAはSony GDM-1960/1961として知られる。
  • ただし、KEK実機でLine Mode BrowserをDECterm上で動かしていたか、コンソールで動かしていたかは未確認。

再現上の代用

表示全体は1280×1024の仮想ラスタとして組み、DECtermを80×24の論理端末として配置しています。原版のDEC bitmap fontはWebページへ埋め込まず、文字幅・行数を優先した固定幅近似です。森田様から実行環境・色・ウインドウ配置を確認できれば、この候補を修正します。
