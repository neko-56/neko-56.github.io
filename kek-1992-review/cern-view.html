推定仕様

場所CERN 共用端末室
端末候補IBM 3270系の固定サイズ表示環境。視覚モデルは 24行×80桁の Model 2 系を基準。
表示単色CRT、緑色蛍光体を基準。IBM 3270系資料では24×80が標準的な画面サイズ。
文字セルIBM 3278系資料の 7×9 dot matrix を参考にしたラスター風近似。
ブラウザLine Mode Browser を第一候補。
操作reference number + RETURN。
未確定森田様が使った実機型番、3270実機かエミュレーションか、文字色、実フォント。

推定根拠

  • 森田様の回顧では、Tim Berners-Lee氏との昼食後に「CERNの端末室」に移動し、そこからKEKへログインしてHTMLを作成。
  • CERN職員の回顧には、初期Line Mode Browserを「fixed size IBM 3270 display」で使った記述がある。
  • CERNの2013年Line Mode Browser再現では、古いIBM端末を実機参照し、画面を接写して文字形状を再構成している。
  • ただし、これらは森田様が1992-09-30に使った端末の直接証拠ではないため、IBM 3270系は「候補」として扱う。

再現上の代用

現代ブラウザだけで当時のIBM端末ROMフォントをそのまま使うことはできないため、ASCII文字は固定幅フォントとラスター化した表示処理で近似しています。機種確定後は、該当端末の字形・文字セル・CRT色に合わせて更新します。
